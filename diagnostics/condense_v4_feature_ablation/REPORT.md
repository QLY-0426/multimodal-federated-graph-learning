## 现状分析

- Movies 特征优化中最佳为 alpha10，相对 raw +2.42 pp。alpha10 相对 alpha0 +3.24 pp。
- Toys 特征优化中最佳为 alpha10，相对 raw +5.54 pp。alpha10 相对 alpha0 +7.53 pp。

教师真实 val、各档 teacher-on-syn、分类与加权对齐损失、梯度范数和归一化特征余弦距离保存在 results.json。V3 的 Toys 删边收益与 V4 的固定边特征收益分属不同干预。

**固定真实诱导边后，对齐项有助于准确率。** alpha10 在两个数据集的三个划分上均取得正的平均配对增益。去掉对齐项的 alpha0 平均掉分，即使它把 teacher-on-syn 从 Movies 的约 60% 和 Toys 的约 89% 提至约 98% 和 100%。单纯提高教师在合成图上的准确率无法保证学生受益。alpha10 的 macro-F1 仍比原始特征低 3.33 pp（Movies）和 0.54 pp（Toys）。Movies 的准确率提升伴随更明显的类别表现损失。

alpha10 的加权对齐梯度在 Movies 第 300 轮约为分类梯度的 11%，在 Toys 则随划分和轮次变化，个别划分末轮可超过分类梯度。数据不支持统一将 feat_alpha 从 10 降到 1。相对 alpha0，alpha10 同时减小了归一化后特征的余弦距离，但仍有明显方向变化。V4 固定了边并关闭平滑项，结论适用于该特征消融协议，不能据此直接推断完整 PGE 流程的最优权重。

## 下一步方案

1. **先做保真特征优化。** 沿用六个划分、相同节点和真实诱导边，保留 raw 及 alpha10 现行结果作为对照。固定 alpha=10，交叉比较 lr_feat={0.05, 0.005} 与余弦锚定系数 λ={0, 0.1}。锚定项为可用模态上的平均 1−cos(当前特征, 初始特征)。其余设置固定，统一用 300 轮特征和三个学生种子评分。该矩阵可以分别估计低学习率和锚定的影响。
2. **候选晋级条件。** 与 raw 同划分同种子配对，平均 val 至少提高 2 pp、至少两个划分的均值为正、macro-F1 均值不下降。按类别记录召回率与预测分布。冻结所选配置后，在已有独立 test 掩码上只做最终核验。
3. **Toys 的结构线单独补齐。** 用 V3 的 k=1 补跑 fixed seed43/44，各三个学生种子，复用 V3 orig 计算配对差。达到加权入度、准确率及 macro-F1 门槛后，再评估训练期度预算，届时以 V4 的固定真实边方案为基线。
