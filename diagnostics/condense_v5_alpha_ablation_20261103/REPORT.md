# V5 feat_alpha 特征消融（2026-11-03）

目的：V4 已证明合成特征内容退化（Movies −11.9 pp、Toys −27.9 pp 相对同数量真实特征）。本轮唯一变量是 `feat_alpha`（传播后类统计对齐损失的权重），检验它是否是特征漂移的直接原因。

协议：只覆盖进程内 config，不写回任何生产源码；凝缩必须重跑，因为 feat_alpha 在 train_syn 内部生效，V1 的 alpha=10 缓存无法复用。数据、划分、学生超参、种子与 V1/V4 完全一致（teacher 200 / condense 300 / student 500，种子 500/501/502）。

生产源码与原始数据运行前后 SHA256 一致性：**True**。

## 判定

- **Movies**：最佳 feat_alpha=0，合成特征 MLP 35.89 （相对 alpha=10 +7.72 pp），GCN 31.08（-0.52 pp），距离同数量真实特征仍差 4.19 pp。降低对齐权重能显著挽回特征质量，说明 feat_alpha 是漂移的直接来源。
- **Toys**：最佳 feat_alpha=1，合成特征 MLP 28.85 （相对 alpha=10 -6.05 pp），GCN 19.23（-4.59 pp），距离同数量真实特征仍差 33.96 pp。降低对齐权重未能显著挽回特征质量，说明漂移还有别的来源（初始化配额、分类损失或 PGE 联动），需另找。

## 边界

只跑了划分种子 42，尚未扩展到 43/44；三个学生种子只消除训练随机性，不消除划分随机性。
val 既参与 V1 选图又用于评分，仍是开发集结果。
本实验只证明 feat_alpha 与特征保真度的关系，不证明端到端 federated 精度会同步改善。
